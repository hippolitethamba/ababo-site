# Site de l'ABABO

Site de l'Association des Bakongo de Boma (ABABO). Site statique : HTML, CSS et JavaScript, sans outil de compilation.

## Fichiers
- `index.html` : le site complet (toutes les pages)
- `404.html` : page d'erreur
- `images/` : photos du site (hero.jpg, communaute.jpg, identite.jpg, patrimoine.jpg, avenir.jpg)
- `og-image.png`, `favicon.svg`, `apple-touch-icon.png` : aperçu réseaux sociaux et icônes
- `sitemap.xml`, `robots.txt` : référencement

## Avant la mise en ligne
1. Remplacer `VOTRE-DOMAINE.org` par le vrai domaine (index.html, sitemap.xml, robots.txt)
2. Compléter les textes entre crochets (conditions générales)
3. Ajouter les photos dans `images/` (moins de 300 Ko chacune)
4. Optionnel : renseigner `ANALYTICS` dans index.html pour la mesure d'audience
